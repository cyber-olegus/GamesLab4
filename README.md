# Лабораторная работа №4: Интерфейсы

Новое решение на C#, .NET 8 и WPF. Откройте GamesLab4.sln в Visual Studio 2022.

- EnemyEditor.Wpf — редактор шаблонов и общий JSON нескольких типов.
- EnemyClicker.Wpf — бой с разными противниками, сохранение и загрузка игрока.
- GamesLab4.Core — модели, BigNumber, интерфейсы и хранение.
- GamesLab4.Checks — консольные проверки на .NET 8.

Команды проверки:

    dotnet build GamesLab4.sln -c Release
    dotnet run --project tests/GamesLab4.Checks/GamesLab4.Checks.csproj -c Release

В архиве для команды: общая основа, два последовательных обновления и итоговое решение.
Исходные PNG из прежних работ можно импортировать кнопкой «Импорт PNG».
